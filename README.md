# World-bank-Api-data-extraction-and-analysis
World Indicators Analysis Dashboard

An interactive data analytics project built using World Bank Open Data API and Power BI to analyze global economic, social, and development indicators from 2016–2024.

This project demonstrates end-to-end data analytics workflow:
Data Extraction → Data Cleaning → Data Modeling → Analysis → Visualization

🚀 Project Overview

The objective of this project is to analyze global development indicators across regions and identify trends, relationships, and economic insights.

The dashboard provides analysis on:

GDP per Capita

Trade Value

Health Expenditure (% of GDP)

GDP Growth Rate

Forest Area Percentage

Internet Penetration

Youth Unemployment Rate

Child Immunization Rate

📥 Data Source

🌐 World Bank Open Data API

Time Period: 2016 – 2024

Data extracted programmatically using API requests

🛠 Project Workflow
1️⃣ Data Extraction

Connected to the World Bank API

Retrieved multiple global indicators

Combined country-level data

Structured dataset for analysis

2️⃣ Data Cleaning & Transformation

Handled missing values

Standardized country and region formats

Created calculated fields

Filtered required time period

3️⃣ Data Modeling

Built relationships between indicators

Designed star schema structure

Created DAX measures for KPIs

4️⃣ Dashboard Development

Designed interactive Power BI report

Implemented region filters

Added trend analysis (2016–2024)

Built relationship visualizations

📊 Dashboard Features

✔ KPI Cards (GDP per Capita, Trade Value, GDP Growth, etc.)
✔ Region Filter
✔ Indicator Trend Line Chart
✔ Age-based and Time-based Analysis
✔ Relationship Between Internet Penetration & Child Immunization
✔ Youth Unemployment vs GDP per Capita Analysis
✔ Interactive Timeline Slider

📌 Key Insights

📈 GDP per capita shows steady growth across developed regions.

🌐 Internet penetration strongly correlates with child immunization rates.

📉 Youth unemployment varies significantly by region.

🌳 Forest area percentage remains stable in some regions but declines in others.

💰 Higher GDP per capita often aligns with higher healthcare spending.
